2. 8-Step Implementation Workflow from Research Notebooks

Direct implementation mapping from 01_acoustic_anomaly_detection.ipynb and 02_reinforcement_learning_control.ipynb.

Step 1

Hydrophone Acoustic Data Ingestion

High-frequency immersion hydrophones record physical sound transients inside the oil tank at 16,000 Hz. Ambient electrical hum (100 Hz magnetostriction) is filtered, isolating partial discharge micro-sparks (10 kHz – 150 kHz).

Dataset: Industrial Substation PD Transients • 48,000 samples/window
Step 2

Log-Mel Feature Spectrogram Generation

Raw audio windows (3.0s duration) are processed via Short-Time Fourier Transform (STFT) with FFT window of 2048 and hop length of 512, mapping sound into 128 triangular Mel-scale frequency bins for neural perception.

Dimensions: 128 Mel bands × 94 time frames • Log-power normalized
Step 3

VoltEchoCNN Deep Classifier Architecture & Training

A 4-stage 2D Convolutional Neural Network with Batch Normalization, Max Pooling, and Dropout (0.3) was constructed and trained with Adam optimizer (lr=0.001) over 25 epochs. Below is the empirical training and validation loss/accuracy progression from 01_acoustic_anomaly_detection.ipynb:

Figure 1: Empirical training loss convergence and validation accuracy progression for VoltEchoCNN across 25 epochs from notebooks/01_acoustic_anomaly_detection.ipynb.
Trained on PyTorch 2.0 • Loss Function: CrossEntropy • Early Stopping at Epoch 22
Step 4

Perception Validation & Metric Verification

The trained CNN model was evaluated against unseen test partitions. Validated results show 85.08% overall accuracy, 0.9258 ROC-AUC, and an F1-score of 0.85, confirming reliable sub-second anomaly discrimination.

Inference Latency: 18.4 ms • TorchScript C++ Export: 1.6 MB
Step 5

Thermodynamic Simulation Environment

A custom Gymnasium environment was built implementing differential thermal equations: dT/dt = (4.2 × L² + 10.0 × P_anom) - 0.09 × (T - T_ambient). Joule heating ($4.2 L^2$) penalizes overloading, while ambient dissipation follows Newton's cooling law.

Gymnasium Discrete(5) Action Space • Box(8,) Continuous Observation
Step 6

8D Markovian State Vector Assembly

To prevent partial observability (POMDP) without recurrent neural network latency, the state vector is augmented with rate-of-change derivatives: S = [P_anom, ΔP_anom, E_acous, Load, ΔLoad, T/100, ΔT/10, t/t_max].

8-Dimensional State Space • Normalized for rapid gradient descent
Step 7

Multi-Objective Anti-Gaming PPO Policy Optimization

The Actor-Critic agent was trained with Stable-Baselines3 PPO using an anti-gaming reward function. Below is the training reward progression and episode length stability curve from 02_reinforcement_learning_control.ipynb:

Figure 2: Reinforcement learning cumulative reward convergence and episodic policy stabilization from notebooks/02_reinforcement_learning_control.ipynb.
PPO Hyperparameters: Clip Range 0.2 • Entropy Coeff 0.01 • 9,862 Tuned Weights
Step 8

Hardware-in-the-Loop Simulation & Stress Testing

The trained PPO checkpoint (soundgrid_integrated_ppo.zip) was deployed to an interactive FastAPI backend. Across 100 Monte Carlo stress episodes under simultaneous 42°C heatwaves and severe arcing faults, the agent achieved a 0.0% burnout rate, a 1-step emergency trip response, and sustained 85% grid throughput.

Production Checkpoint: PyTorch / ONNX Runtime • FastAPI Live Serving

3. System Algorithms (Plain English Pseudocode)

Written in clear, structured, readable pseudocode without programming syntax, so that professors, thesis evaluators, and power engineers can easily review every decision rule and mathematical formulation.

Algorithm 1

Real-Time Acoustic & PPO Transformer Protection Control Loop

Inputs: Continuous acoustic signal stream x(t), Core oil temperature T(t), Ambient temperature T_amb, Grid load request L(t).
Outputs: Discrete control action a_t ∈ {0, 1, 2, 3, 4}, Updated circuit breaker state, New dispatch setpoint.
Execution Interval: Evaluated every time step Δt (e.g., 3.0-second telemetry window).
  1. Step 1: Acoustic Ingestion & Windowing

    Capture 3.0 seconds of audio data (48,000 samples at 16,000 Hz) from immersion piezoelectric hydrophones mounted inside the transformer oil tank.

  2. Step 2: Log-Mel Feature Transformation

    Apply Short-Time Fourier Transform (STFT) with window size 2048 and hop length 512. Project frequency bins into 128 log-spaced Mel filterbanks, generating Mel spectrogram matrix M_t.

  3. Step 3: Neural Perception Inference

    Pass spectrogram M_t through the trained VoltEchoCNN model. Output the continuous anomaly probability P_anom ∈ [0, 1] and calculate normalized Root Mean Square acoustic energy E_acous.

  4. Step 4: Derivative Rate Computation & State Assembly

    Compute first-order differences to track system inertia:
    • Anomaly Growth Rate: ΔP_anom = P_anom(t) − P_anom(t-1)
    • Load Change Rate: ΔL = L(t) − L(t-1)
    • Thermal Heating Rate: ΔT = T(t) − T(t-1)
    Assemble the normalized 8-dimensional state vector:
    S_t = [P_anom, ΔP_anom, E_acous, L, ΔL, T/100, ΔT/10, t/t_max].

  5. Step 5: PPO Policy Inference

    Forward state vector S_t through the trained PPO Actor neural network to produce probability distribution over actions: π_θ(a | S_t). Select the optimal control action a_t = argmax π_θ(a | S_t).

  6. Step 6: Substation Actuation & Protection Dispatch

    If action is 4 (Emergency Trip):
     • Instantly open the primary substation circuit breaker.
     • Set delivered load to 0% and alert utility dispatchers to prevent explosion.
    Else if action is 3 (Throttle 40%):
     • Modulate inverter tap changers to derate load by 30% to shed core heat quickly.
    Else if action is 2 (Throttle 15%):
     • Gently reduce load by 15% to stop early thermal drift without disturbing normal grid supply.
    Else if action is 1 (Increment Load):
     • Increase transmission load by +10% if thermal margin allows (temperature < 75°C).
    Else (Action is 0: Maintain Load):
     • Maintain current transmission throughput unchanged.

  7. Step 7: Thermodynamic State Propagation

    Calculate next internal core temperature T(t+1) using the heat balance differential equation:
    dT/dt = (4.2 × Load² + 10.0 × P_anom) − 0.09 × (T − T_amb)
    Update T(t+1) = T(t) + Δt × (dT/dt) and store current telemetry for the next cycle.

  8. Step 8: Repeat Loop

    Advance time counter t ← t + 1 and return to Step 1 for real-time continuous closed-loop surveillance.

Algorithm 2

Anti-Gaming Multi-Objective Reward & Penalty Function

Purpose: Guide the PPO agent during training to balance maximum power delivery against insulation burnout, false blackouts, and mechanical wear.
Total Reward at Step t: R_t = R_delivery + R_thermal + R_burnout + R_blackout + R_damping
  1. Rule 1: Base Power Delivery Reward

    R_delivery = +35.0 × Load_t
    Provides a continuous positive reward proportional to delivered electricity, encouraging the agent to keep transformers transmitting power at high efficiency whenever safe.

  2. Rule 2: High-Temperature Stress Penalty

    Condition: If core oil temperature T_t > 80.0°C:
    R_thermal = −2.5 × (T_t − 80.0)
    Provides a continuous linear penalty gradient discouraging the agent from allowing oil temperatures to climb into winding degradation territory.

  3. Rule 3: Catastrophic Burnout Penalty (Terminal Event)

    Condition: If core oil temperature reaches or exceeds T_t ≥ 130.0°C:
    R_burnout = −180.0, and abort the training episode immediately.
    Severe terminal punishment ensuring the agent never allows physical catastrophic tank explosion or oil vapor ignition.

  4. Rule 4: Spurious False Blackout (False Trip) Penalty

    Condition: If the agent commands an emergency trip (a_t = 4) when acoustic anomaly risk is low (P_anom < 0.35) and temperature is safe (T_t < 90.0°C):
    R_blackout = −160.0
    Anti-Gaming Mechanism: Without this penalty, RL agents learn to "cheat" by tripping healthy transformers to avoid all thermal penalties. This penalty forces the agent to keep supplying power unless genuine danger exists.

  5. Rule 5: Switchgear Mechanical Wear Damping

    R_damping = −12.0 × |ΔLoad_t|
    Penalizes erratic oscillations and frequent tap-changer switching to preserve physical contactors and prevent mechanical wear.

  6. Rule 6: Final Reward Aggregation

    Return total scalar reward R_t to the PPO optimization algorithm to update policy weights via Generalized Advantage Estimation (GAE).
